# Begin with one collection

Great Rabbis Skills is a library of small agent workflows. Start with the kind of attention the work needs, then choose the smallest practice that can return a useful artifact.

## Install the library

```bash
npx skills@latest add YitziG/great-rabbis-skills
```

The repository is public; the installer can list or select individual skills.

## Choose a characteristic lens

1. Choose **Rabbi Nachman** when the work needs renewal, a concrete good point, courage, simplicity, or story.
2. Choose **the Rebbe** when an idea needs a mission, deed, person-centered reach, or a way to multiply capability.
3. Choose **Rav Kook** when the work needs authentic return, multiple scales, integration, principled balance, or imagination.

Choose one practice. Run it to its observable output, then decide whether another practice is needed.

## Keep the boundary visible

These are modern practices inspired by documented themes. They are not quotations, religious rulings, therapy, or simulated spiritual authorities.
