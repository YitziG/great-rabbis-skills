# Install the skills

## Inspect what is available

```bash
npx skills@latest add YitziG/great-rabbis-skills --list
```

## Install interactively

```bash
npx skills@latest add YitziG/great-rabbis-skills
```

## Install one practice

```bash
npx skills@latest add YitziG/great-rabbis-skills --skill bottom-line-action
```

## Install globally for Codex

```bash
npx skills@latest add YitziG/great-rabbis-skills -g -a codex
```

The repository is public. Inspect a skill's `SKILL.md`, source boundary, and invocation policy before installing it.
