# Choose a practice

Start with the dominant constraint, not the most famous name or the practice title that sounds most attractive.

| What is happening | Start here |
| --- | --- |
| Work has stalled or feels spoiled | [begin-again](/rabbi-nachman/practices/begin-again) |
| Failure has hidden all evidence of capacity | [nekudah-tovah](/rabbi-nachman/practices/nekudah-tovah) |
| The plan is heavier than the intended result | [simple-path](/rabbi-nachman/practices/simple-path) |
| Fear is setting the boundary | [narrow-bridge](/rabbi-nachman/practices/narrow-bridge) |
| An inspiring discussion has produced no change | [bottom-line-action](/lubavitcher-rebbe/practices/bottom-line-action) |
| The whole obligation is preventing one useful act | [one-more-good-deed](/lubavitcher-rebbe/practices/one-more-good-deed) |
| Outreach has lost sight of the recipient | [reach-the-one](/lubavitcher-rebbe/practices/reach-the-one) |
| One expert has become the bottleneck | [make-a-lamplighter](/lubavitcher-rebbe/practices/make-a-lamplighter) |
| A decision serves one scale while ignoring the others | [fourfold-song](/rav-kook/practices/fourfold-song) |
| Competing positions each claim to be the whole truth | [whole-from-parts](/rav-kook/practices/whole-from-parts) |
| Strict consistency and humane context appear incompatible | [justice-and-mercy](/rav-kook/practices/justice-and-mercy) |
| Symptom fixes keep producing the same failure | [root-cause-return](/rav-kook/practices/root-cause-return) |

Use [find-a-practice](/rabbi-nachman/practices/find-a-practice) when the routing within the Rabbi Nachman collection is unclear. Cross-collection routing remains a human choice because the collections offer different lenses, not a single ranking of spiritual authorities.
