# Privacy

The Great Rabbis Skills site is a static documentation site. The application does not include analytics, advertising, accounts, forms, comments, or a database, and it does not ask visitors to submit reflective answers.

The site host and a visitor's browser or network provider may still process ordinary request metadata such as IP address, user agent, requested URL, and time under their own policies. Repository interactions on GitHub are governed by GitHub's terms and privacy statement.

Installed skills run inside the user's chosen agent environment. This repository cannot control that environment's retention or data practices. Skills that invite reflection are designed to keep the answers off-chat unless the user explicitly chooses otherwise.
