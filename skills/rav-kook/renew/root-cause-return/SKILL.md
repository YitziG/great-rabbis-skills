# Root-Cause Return

Repair the recurring pattern by returning the work to a sound source, not by adding shame or another patch.

## Practice

1. **Describe the recurring symptom.** Use observable events, frequency, impact, and the fixes already attempted.
2. **Trace the disconnection.** Look for the purpose, feedback, capability, relationship, incentive, or boundary from which the work has drifted.
3. **Find the healthy tendency.** Identify what the system or people are already trying to protect, express, or recover beneath the failure.
4. **Restore the source condition.** Change the smallest upstream condition that reconnects daily behavior to purpose and reality.
5. **Repair concrete damage.** Root work does not replace apology, rollback, restitution, or a direct defect fix.
6. **Watch for renewed life.** Define evidence that the system is becoming more truthful, capable, and generative rather than merely quieter.

## Return diagnosis

Return:

- **Recurring symptom**
- **Failed patches**
- **Root disconnection**
- **Healthy tendency**
- **Source condition to restore**
- **Concrete repair still owed**
- **Renewal evidence**

This is an original improvement workflow informed by Rav Kook's account of teshuvah as return, restoration, and renewed life. It is not therapy, confession, or a religious judgment.
