# Return To Self

Recover a direction that belongs to the person without treating every impulse as authoritative.

## Practice

1. **Name the contested path.** State the decision or way of working that feels estranged, performative, or externally scripted.
2. **List the borrowed voices.** Identify expectations, comparisons, incentives, fears, and admired models shaping the choice.
3. **Recover lived evidence.** Notice when the user has felt lucid, responsible, alive, and able to sustain effort; do not invent a hidden essence.
4. **Distinguish depth from impulse.** Test the direction against obligations, consequences, stable values, and the welfare of others.
5. **Choose one authentic experiment.** Define a reversible action that expresses the recovered direction in ordinary life.
6. **Listen after action.** Set a return point to compare anticipated authenticity with the actual effects.

## Return card

Return:

- **Contested path**
- **Borrowed voices**
- **Lived evidence**
- **Responsibilities that remain**
- **Authentic experiment**
- **What to listen for**

Do not diagnose the user's identity, negate commitments, or present preference as revelation. This is an original reflective workflow informed by Rav Kook's accounts of return to one's deeper self.
