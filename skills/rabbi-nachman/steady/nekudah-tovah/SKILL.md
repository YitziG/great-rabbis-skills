# Nekudah Tovah

Find evidence, not compliments.

Do not automatically apply this spiritually branded frame to a personal judgment about someone. In that context, proceed only after the user explicitly chooses this skill.

## Practice

1. **Name the difficulty intact.** State the loss, failure, conflict, or constraint without softening it.
2. **Search four places for evidence:**
   - Something that worked, even briefly.
   - Something worth protecting that was preserved.
   - Something learned that changes the next attempt.
   - A person, tool, habit, or resource that is genuinely available.
3. **Reject counterfeit points.** Remove generic praise, speculation about motives, and anything contradicted by the record.
4. **Choose the living point.** Select the one good point with the most leverage for the next move.
5. **Build from it.** Propose one action that uses that point without pretending the difficulty is resolved.

## Output

Return:

- **The difficulty**
- **Evidence of good**
- **The living point**
- **What it makes possible**
- **One next move**

If no good point is supported yet, say what evidence is missing. Do not manufacture positivity to complete the template.
