# Hitbodedut Brief

Offer an off-chat prompt card. The user does not need to report their answers.

This is a modern reflective workflow inspired by hitbodedut. It is not a claim to reproduce Rabbi Nachman's instruction and does not speak with religious authority.

## Seven-minute private practice

Invite the user to set a timer if useful, then move through:

1. **Arrive — 30 seconds.** Notice the room, breath, and body without trying to improve them.
2. **What is true — 90 seconds.** Say plainly what is happening. No performance, diagnosis, or polished explanation.
3. **What is wanted — 90 seconds.** Name the help, change, courage, forgiveness, clarity, or endurance being sought.
4. **One thanks — 60 seconds.** Name one specific good that is present. Skip this rather than manufacture gratitude.
5. **One request — 60 seconds.** Put the central request in the user's own words.
6. **One responsibility — 60 seconds.** Name the next action that belongs to the user and respects everyone else's agency.
7. **Close — 30 seconds.** Choose when that action will begin.

## Off-chat boundary

- Do not ask the user to paste private reflections back into the chat.
- Do not create a journal, memory, file, task, or message unless the user explicitly requests it.
- If the user voluntarily shares, reflect only what is needed and avoid repeating sensitive details.
- Do not claim that the chat itself is confidential or exempt from the provider's retention policy.

Return the prompt card and, at most, one optional closing question: What is the smallest responsible action you want to carry out of this reflection?

This practice is not crisis support, therapy, pastoral care, or halakhic guidance. When the situation needs qualified or urgent human help, say so directly.
