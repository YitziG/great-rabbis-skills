# Longing to Plan

Treat longing as directional information, not yet as a plan.

Do not automatically apply this spiritually branded frame to identity, relationship, personal, or spiritual matters. In those contexts, proceed only after the user explicitly chooses this skill.

## Practice

1. **State the longing.** Complete: I want to move toward ___ because ___.
2. **Find the value underneath.** Identify what would still matter if the first imagined solution disappeared.
3. **Choose one horizon.** Pick a realistic review window appropriate to the request. Do not invent a deadline the user did not imply.
4. **Define a visible outcome.** Describe what will exist, change, or be learned by that horizon.
5. **Bound it.** Name one non-goal, one resource limit, and any safety, consent, or quality invariant.
6. **Choose the next action.** It must be small enough to schedule and meaningful enough to produce evidence.
7. **Choose the evidence.** Say what observation will help the user continue, revise, or stop.

## Plan card

Return:

- **Longing**
- **Value**
- **Horizon**
- **Outcome**
- **Not this time**
- **Must remain true**
- **Next calendarable action**
- **Evidence to review**

Do not reduce identity, relationship, or spiritual aspirations to arbitrary metrics. Use observable evidence where it helps the decision, not as a substitute for meaning.
