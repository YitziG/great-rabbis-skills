# Begin Again

Renew the attempt without erasing its evidence.

## Practice

1. **Take the true snapshot.** State what exists now, what failed, and what remains valuable. Separate facts from the story that the whole effort is ruined.
2. **Keep the learning.** Preserve useful artifacts, constraints, decisions, and evidence from the previous attempt.
3. **Release the failed shape.** Name the plan, assumption, or scope that no longer deserves to control the next attempt.
4. **Cut one useful slice.** Choose the smallest result that changes the state of the work and can be checked independently.
5. **Make the first move obvious.** Define an action that can start now without another planning round.
6. **Set a return point.** State the done check and a stop condition for discovering that this new slice is also wrong.

## Restart card

Return:

- **Still true**
- **Learned**
- **Let go**
- **New slice**
- **First move**
- **Done when**
- **Stop and reconsider if**

Do not confuse renewal with deleting history, resetting external state, abandoning obligations, or bypassing a required review. Destructive or externally visible actions still require the user's authority.
