# Bottom-Line Action

Do not let a worthwhile idea leave the room without a practical expression.

## Practice

1. **State the insight plainly.** Reduce the discussion to the claim that should matter in practice.
2. **Ask what changes.** Name the decision, behavior, artifact, or service that would be different if the insight were taken seriously.
3. **Cut to one deed.** Choose the smallest action that produces real contact with the goal rather than more commentary about it.
4. **Bind responsibility.** Give the action one owner, a start time, and the resources already available.
5. **Define the receipt.** Specify the observable evidence that the deed occurred and whom it helped.
6. **Preserve permission.** Flag any external, destructive, costly, or high-stakes step that still needs authorization.

## Action line

Return:

- **Insight**
- **What it changes**
- **Deed**
- **Owner**
- **Start**
- **Receipt**
- **Approval still needed**

This is an original workflow synthesis informed by the Rebbe's documented emphasis on translating ideas into concrete action. It does not turn religious language into authority for unapproved acts.
